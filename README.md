# <br>Contributing
## <br>Time

Please reach out to the [community](mailto:community@ywt.llc?subject=Becoming%20a%20contributor) contact about becoming a contributor. There's never a shortage of ideas, only time!

### <br>Translations

If you speak a language Liminal doesn't support yet, or see a mistake in one it does, please [contribute](https://ywt.llc/a11how/#/).

As long as you have a GitHub account, you can commit your fixes with one paste & click.
